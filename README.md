# Tesla's Cabinet

The main inspiration for this mod is, obviously, teslapunk aesthetic. The idea behind this is that current mods for as
far as I am aware provide little decorative blocks in this area, that's why I have decided to model and add some of
these items myself. Decoration first, and functionality later, so this mod is aimed at **builders mostly**.

### Current features:
- Decorative shelves made of all types of wood for building custom cabinets/wardrobes;
- Microscopes. For now, 2 types of microscopes, planning on adding more.
- Alchemical equipment: alembic.
- Static electricity dome block.
- Tungsten lamps that shine when powered.
- A phonograph with wax cylinders.
- Uranium glassware!
